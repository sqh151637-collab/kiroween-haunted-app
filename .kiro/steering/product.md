# Product Vision — Haunted Spell Book

> Scaffolding for Kiroween 2026 · Costume Contest. Expand while building in Kiro.

## Pitch
A haunting, polished **Spell Book** — a to-do list dressed as a witch's grimoire.
The spooky UI is not decoration: fog, flicker, and fade-into-the-beyond feedback
make completing tasks feel like banishing spirits. Design enhances function.

## Category
**Costume Contest** — any app with a haunting, polished, spooky UI where the
spooky design enhances function.

## Core experience
- Dark, candlelit spell-book aesthetic
- Tasks as "incantations" / spells to cast
- Completing a task fades it into the beyond (ghost dissolve)
- Soft fog, candle flicker, ghost cursor trail for presence
- Local-first: spells persist in the browser (localStorage)

## Non-goals (v1)
- Accounts, sync, or backend
- Mobile-native apps (responsive web is enough)
- Heavy frameworks / build steps

## Success for Kiroween
- Public repo with OSI license visible in GitHub About
- `/.kiro` at repo root (steering, specs, hooks) — not gitignored
- Live demo URL (GitHub Pages)
- Short demo video + Devpost write-up
- All work after Oct 30, 2026
