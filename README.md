# Haunted Spell Book

**Kiroween 2026 · Costume Contest** entry — a haunting, polished spooky to-do app shaped like a witch’s grimoire. Completing a task fades it *into the beyond*; fog, candle flicker, and a ghost cursor trail make the UI part of the product, not just decoration.

Built with [Kiro](https://kiro.dev) (steering, specs, hooks under `/.kiro`).

## Demo

- Open [`index.html`](./index.html) in a browser, **or**
- `npx serve .` and visit the printed local URL
- Live Pages URL (after deploy): `https://sqh151637-collab.github.io/kiroween-haunted-app/`

## Features

- Inscribe spells (tasks), cast them (complete), or banish them (delete)
- Cast animation: dissolve / fade into the beyond
- Fog layers, candle flicker, ghost pointer trail
- `localStorage` persistence
- `prefers-reduced-motion` support
- Zero build step; optional Google Fonts only
